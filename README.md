# Netflix Clone

A responsive Netflix Clone built using only HTML and CSS. This project replicates the look and feel of Netflix's homepage, featuring a hero section, multiple content sections, and a clean, modern UI.

## 🚀 Features
- Fully responsive design
- Attractive hero section with a call-to-action
- Multiple content sections showcasing Netflix features
- Clean and modern UI/UX
- No JavaScript, only HTML and CSS

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox & Grid for layout, animations for effects)

## 🎯 How to Run the Project
1. Clone the repository:
   ```sh
   git clone https://github.com/yourusername/netflix-clone.git
   ```
2. Navigate to the project directory:
   ```sh
   cd netflix-clone
   ```
3. Open `index.html` in your browser.
